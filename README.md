The data to train the model is available at this link : https://drive.google.com/drive/folders/1KniQd6NFCiNNE6X1PvCrpy4Mc_DicBXp?usp=sharing.

All codes are in the "code" folder

Generated data, embeddings, molecule samples, evaluation results, model weights,
checkpoints, and runtime logs are excluded from Git by `.gitignore`. Keep these
files locally; a fresh clone needs the training data from the link above and
must regenerate outputs or obtain the required pretrained weights separately.
The `REWORKED_CODE/Random_Forest/RF.ipynb`, preprocessing, pretraining, and testing
notebooks produce the corresponding artifacts. Source notebooks, scripts,
configuration files, and the small Hansen source datasets remain tracked.
